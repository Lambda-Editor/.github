# Lambda

Official GitHub organization for **Lambda**, a lightweight retro game engine and editor focused on making development as painless as possible—abstracting away legacy toolchains and low-level hardware friction so you can build cleanly without fighting setup.

Here you'll find repositories across the Lambda ecosystem, including:
- Core engine, runtime, and editor repositories built to simplify retro and cross-platform workflows.
- Tooling, shader/asset utilities, and sample or experimental projects across supported targets.

If a repository's license or status is unclear, please check its `LICENSE` and `THIRD_PARTY_LICENSES` files before using or distributing it.

## Engine & Editor Repositories

Lambda is free and open source, designed to keep the runtime lean and take the pain out of legacy toolchains, build steps, and console/hardware quirks.

Repositories in this group cover:
- Core engine and rendering runtime
- Editor and workflow tooling
- Asset/shader pipelines and platform support

Please note:
- Each repository specifies its own license and dependency notices in its root `LICENSE` and `THIRD_PARTY_LICENSES` files.
- Third-party libraries included under `vendor/` remain governed by their respective licenses (i.e. MIT, BSD, or LGPL).
